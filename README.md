# Minecraft 物品圖鑑與合成指南

查詢 Minecraft 常見物品的用途、取得方式與合成配方。App 提供「圖鑑」、「分類漫遊」、「合成指南」與「官方網站」四個分頁。

## 圖鑑

- 點選分類，瀏覽方塊、工具、武器與護甲、食物、材料、紅石與運輸等物品。
- 在搜尋欄輸入中文或英文名稱，尋找物品。
- 點選物品，查看用途與取得方式。
- 若物品有收錄配方，可點選「查看合成指南」查看製作方式。
- 點選左上角返回按鈕，回到列表。

## 分類漫遊

- 左右滑動畫面，切換不同物品分類。
- 點選物品，進入詳細介紹頁。
- 透過頁數文字與下方圓點，確認目前瀏覽的位置。

## 合成指南

- 瀏覽配方列表，或搜尋物品名稱及材料中文名稱。
- 點選配方，查看 **3 × 3 工作台**的材料擺放位置。
- 依照格子圖放置材料，空白格不放任何物品。
- 下方「材料清單」列出合成一次所需的材料數量，「產出」顯示完成後可獲得的物品數量。

合成指南以 **Minecraft Java 版 1.21.4** 為資料版本，提供配方查詢，無法直接在 App 內製作或取得遊戲物品。

## 官方網站

點選「官方網站」分頁，即可在 App 內瀏覽 Minecraft 官方網站。此功能需要網路連線。

## 使用提醒

本 App 收錄部分常見物品與配方，並非完整遊戲資料庫。不同遊戲版本的配方與取得方式可能有所差異。
